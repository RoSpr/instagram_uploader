# Публикация фотографий в Инстаграм

photo_downloader.py скачивает выбранные пользователем фотографии запуска SpaceX и указанной пользователем коллекции Hubble, уменьшает их размеры до 700x700px и делает фотографии квадратными за счёт добавления чёрных полос с двух сторон. 
instagram_uploader.py публикует выбранную пользователем фотографию из папки 'images' в Инстаграм.

### Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

Чтобы запустить скрипт, необходимо выполнить bash-команду, зайдя в директорию с программой через командную строку:
```
python instagram_uploader.py
```

или, если есть конфликт с Python2:
```
python3 instagram_uploader.py
```
